Готово. Создан класс `Fb2ToHtmlConverter` для преобразования FB2 в HTML с оглавлением.

## Что сделано

Новый модуль `pyFB2/pyFB2/fb2_to_html.py` (~640 строк), переиспользующий `Fb2Parser` и структуры `fb2_structures.py`. Не требует внешних зависимостей.

### Публичный API (в стиле `Fb2ToMarkdownConverter`)
```python
from pyFB2.fb2_to_html import Fb2ToHtmlConverter

converter = Fb2ToHtmlConverter(image_dir="images", include_toc=True)
html = converter.convert("book.fb2")          # → HTML-строка
path = converter.write("book.fb2", "book.html")  # → файл + выгрузка картинок
converter.save_images("some_dir")             # отдельная выгрузка изображений
```

### Оглавление (главная фича)
- Каждой секции/главе присваивается якорь (`id="sec-N"`), а заголовки ссылаются на него.
- TOC строится **вложенным списком** по уровням заголовков (часть → глава → раздел).
- Параметры: `include_toc=True/False`, `toc_title="Оглавление"`.
- Алгоритм: собираю плоский список `(level, anchor, title)` при обходе, затем строю дерево (стек уровней) и рендерю рекурсивно `<ul><li><a href="#sec-N">…`.

Пример сгенерированного TOC:
```html
<nav class="toc">
  <h2>Оглавление</h2>
  <ul><li><a href="#sec-1">Часть первая</a>
    <ul><li><a href="#sec-2">Глава 1</a>
      <ul><li><a href="#sec-3">Раздел 1.1</a></li></ul></li>
      <li><a href="#sec-4">Глава 2</a></li></ul></li></ul>
</nav>
```

### Что ещё реализовано
- **Метаданные**: заголовок книги, авторы, жанры, обложка, аннотация.
- **Заголовки** секций → `<h1>`–`<h6>` с якорями (уровень настраивается через `heading_offset`).
- **Разметка**: `<strong>`, `<em>`, `<del>`, `<sub>/<sup>/<code>`, `<span class>`, `<a href>`, `<img>`.
- **Блоки**: `<p>`, подзаголовки, `<blockquote>` (cite/epigraph), стихи (`div.poem/stanza/verse`), `<table>`, пустые строки.
- **Изображения**: файлы в `image_dir` **или** встроенные `data:`-URI (режим `inline_images=True` — единый самодостаточный HTML-файл).
- **Встроенный CSS** (`DEFAULT_CSS`, можно заменить через параметр `css`).
- Полноценный HTML5-документ с `<meta charset="utf-8">` и `<style>`.

### Сноски: переходы «туда и обратно»

Сноска в FB2 — это `<a type="note" l:href="#note1">1</a>` в тексте и секция
`<section id="note1">` (обычно в отдельном `<body name="notes">`). Экспортёр
делает ссылки двусторонними (включено по умолчанию, отключается
`note_links=False`):

```html
<!-- в тексте: ссылка на сноску + якорь для возврата -->
<p>Текст со сноской<a class="note-ref" id="noteref-note1" href="#note1">1</a>.</p>

<!-- сама сноска: id из FB2 + обратная ссылка -->
<div class="body notes">
  <section id="note1" class="footnote">
    <h2 id="sec-3">1</h2>
    <p>Текст сноски.</p>
    <p class="footnote-back"><a href="#noteref-note1">↩</a></p>
  </section>
</div>
```

| Что | Как получается |
|---|---|
| переход в сноску | `href="#<id секции>"`; секция-сноска получает `id` из FB2 |
| возврат в текст | якорь `id="noteref-<id>"` у ссылки + `href="#noteref-<id>"` в сноске |
| несколько ссылок на одну сноску | уникальные якоря: `noteref-note1`, `noteref-note1-2`, … (id в HTML не повторяются) |
| стили | `a.note-ref`, `section.footnote`, `p.footnote-back` в `DEFAULT_CSS` |
| отключить | `Fb2ToHtmlConverter(note_links=False)` — ссылки останутся обычными `<a href="#…">` |

**Какие ссылки считаются сносками.** В разных книгах сноски оформлены
по-разному, поэтому учитываются оба варианта:

* `<a type="note" l:href="#n1">` (или `type="endnote"`);
* любая ссылка, ведущая на секцию из тела примечаний
  (`<body name="notes">`, `footnotes`, `endnotes`, `comments`,
  `commentaries`) — **даже без `type`**, как в большинстве файлов:
  `<a l:href="#n_2">[2]</a>`.

Обычные ссылки (например, из текста на главу) сносками не считаются и
рендерятся как раньше. Ссылки читаются и с `l:href`, и с `href`.

**Оглавление.** Заголовки сносок — это их номера, поэтому они не попадают в
оглавление и рендерятся как `<p class="footnote-title">1</p>`; в оглавление
попадает только раздел примечаний (`<body name="notes"><title>`).

Список id сносок доступен после конвертации: `converter.note_targets()` →
`["note1", "note2"]`.

Обратная конвертация (`html_to_fb2`) понимает эту разметку: `class="note-ref"`
→ `type="note"`, `p.footnote-back` отбрасывается, `id` сноски сохраняется,
поэтому round-trip «FB2 → HTML → FB2» не теряет сноски и не ломает ссылки.

### Проверка
- Модуль компилируется.
- Сгенерированный HTML **well-formed** (парсится как XML, root `<html>`).
- Оглавление: 4 ссылки ↔ 4 якоря, вложенность корректна.
- Обложка, inline-картинки, таблица, стихи — на месте; изображения выгружаются.
- Режим `inline_images=True` подтверждён (data-URI, без ссылок на файлы).
- Сноски: 3 ссылки из текста ↔ 2 секции-сноски ↔ 2 обратные ссылки; все
  переходы разрешаются, `id` уникальны (тесты `tests/test_html_notes.py`).
- Сноски без `type="note"` (как в реальных файлах, например `test.fb2`):
  18 ссылок ↔ 18 обратных, все переходы разрешаются; заголовки сносок не
  попадают в оглавление.

### Замечание
Пакет установлен **не-editable** — модуль появится в `import pyFB2.fb2_to_html` после `pip install .` из `pyFB2/` (или добавьте исходный каталог в `PYTHONPATH`). Кстати, этот класс как раз закрывает практическую цель из вашего прошлого вопроса: HTML-вывод с оглавлением можно скармливать `THTMLView` (или любому WebView) напрямую.
