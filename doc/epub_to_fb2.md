Готово. Я написал класс `EpubToFb2Converter` для преобразования EPUB в FB2.

## Что сделано

Создан файл `pyFB2/pyFB2/epub_to_fb2.py` (~1100 строк), встроенный в существующий пакет `pyFB2` и переиспользующий структуры из `fb2_structures.py`.

### Публичный API
```python
from pyFB2.epub_to_fb2 import EpubToFb2Converter

converter = EpubToFb2Converter()
path = converter.write("book.epub", "book.fb2")   # файл → файл
book = converter.convert("book.epub")              # → структура FictionBook
xml  = converter.to_xml(book)                      # → XML-строка FB2
```

Класс принимает путь (`str`/`Path`) или содержимое EPUB в виде `bytes`.

### Что реализовано
- **Чтение EPUB**: `zipfile` → `META-INF/container.xml` → OPF (с фолбэком на первый `.opf`).
- **Метаданные** `<dc:*>` → `<title-info>`/`<document-info>`: название, авторы (разбор «Фамилия Имя Отчество» и «Фамилия, Имя»), язык, идентификатор, дата, аннотация, жанры (сопоставление `dc:subject` с `resources/genres.json`, фолбэк `"prose"`).
- **Обложка**: EPUB2 `<guide>` и EPUB3 `<meta name="cover">`/`cover-image` → `<coverpage>` со ссылкой `#id`.
- **Изображения** (`image/*` из манифеста + inline `data:`-URI) → `<binary>` (base64).
- **Контент** из `<spine>`: заголовки `h1–h6` → иерархия `<section>/<title>`; `<p>`, `<strong>/<b>`, `<em>/<i>`, `<a>`, `<img>`, `<sub>/<sup>/<code>/<strike>`, `<blockquote>→<cite>`, `<ul>/<ol>`, `<table>`, `<pre>`, `<hr>`.
- **Корректный mixed-content**: текст правильно распределяется по `text`/`tail`, сохраняя порядок inline-разметки.
- **Валидность по XSD**: при наличии у секции и контента, и подсекций контент оборачивается в анонимную `<section>`, что соответствует схеме `sectionType` (choice).
- Обработка «грязного» XHTML (именованные сущности вроде `&nbsp;` → `&#160;`).

### Разделы и текст (EPUB, собранный из FB2)

Сторонние конвертеры (например FB2EPUB) отдают главы так:

```html
<body class="z"><span><span id="id4">
  <div class="title2"><p class="p1">1. Характер эпохи и масштабы личности</p></div>
  <p class="p">Текст главы…</p>
  <p class="empty-line"/>
</span></span></body>
```

Что делает `EpubToFb2Converter`:

- **обёртки** (`<span>` вокруг `<div>`/`<p>`) обходятся как контейнер — иначе текст
  книги терялся и получался FB2 с одним оглавлением;
- **разделы** берутся из оглавления EPUB (`nav.xhtml` для EPUB3, `toc.ncx` для EPUB2),
  заголовки `<h1>`–`<h6>` внутри документа дают подсекции;
- **заголовок, продублированный в тексте** (`<div class="title1"><p>Глава 1</p>
  <p>КТО СУДЬИ…</p></div>`), пропускается — текст уже есть в `<title>` (сравнение
  по тексту без пробелов, поэтому многострочный заголовок тоже распознаётся);
- **документы `spine` без записи в оглавлении** распределяются по порядку чтения:
  до первого раздела — в начальную секцию (титул), между разделами — в текущую
  (продолжение главы, разбитой на несколько XHTML), после последнего раздела —
  в завершающую секцию (сноски, приложения);
- пустой `<p/>` / `<p class="empty-line"/>` → `<empty-line>`.

### Проверка
Модуль компилируется (`py_compile`), сгенерированный FB2 проверен валидатором проекта `Fb2Validator` по `FictionBook.xsd` — **0 ошибок, документ well-formed**.

### Важное замечание
Пакет `pyFB2` установлен в окружении **не-editable** (копией в `.venv\Lib\site-packages\pyFB2`), поэтому новый модуль появится в импорте только после переустановки:
```
pip install .   # из каталога pyFB2/ (где setup.py)
```
Либо можно добавить исходный каталог в `PYTHONPATH`.

### Ограничения
- Списки превращаются в абзацы (FB2 не имеет списков).
- Вложенные списки и `<figcaption>` упрощаются.
- XHTML парсится через `xml.etree.ElementTree` (толерантно после нормализации сущностей); SVG-обложки игнорируются как `<binary>` для FB2.
