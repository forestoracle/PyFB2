# PDF → FB2 (`pdf_to_fb2`)

Класс `PdfToFb2Converter` — обратное преобразование PDF → FictionBook.
PDF — формат **фиксированной вёрстки** без семантики, поэтому структура и
абзацы восстанавливаются **эвристически**; результат обычно требует ручной
вычитки.

```python
from pyFB2.pdf_to_fb2 import PdfToFb2Converter

converter = PdfToFb2Converter()
book = converter.convert("book.pdf")     # структура FictionBook
xml  = converter.to_xml(book)            # XML FB2
path = converter.write("book.pdf", "book.fb2")
```

Требует пакет `pypdf` (extra `pyFB2[pdf]`).

## Что реализовано

- **Метаданные** `/Info` (`/Title`, `/Author`) → `<title-info>`; автор
  разбирается как «Имя Фамилия» / «Фамилия, Имя».
- **Структура глав** — из закладок PDF (outline): иерархия
  `section`/`title` повторяет вложенность закладок; текст раскладывается по
  секциям по номеру страницы и координате заголовка.
- **Абзацы** — строки группируются в абзацы по отступу первой строки и
  вертикальному интервалу, переносы слов склеиваются, большие промежутки →
  `<empty-line>`.
- **Без закладок** (`use_outline=False` или их нет) структура строится по
  размеру шрифта: крупные строки → заголовки, уровни — по убыванию размера.
- Итог сериализуется `Fb2Writer` и проходит XSD-валидацию.

## Параметры

| Параметр | По умолчанию | Назначение |
|---|---|---|
| `default_genre` | `prose` | жанр (в PDF жанров нет) |
| `lang` | `ru` | язык книги |
| `program_used` | `pyFB2` | значение `<program-used>` |
| `use_outline` | `True` | восстанавливать структуру по закладкам PDF |
| `detect_headings` | `True` | заголовки по размеру шрифта (без закладок) |

## Ограничения

- PDF не хранит семантику: заголовки/абзацы/сноски восстанавливаются
  приблизительно, возможны ложные срабатывания.
- Колонтитулы, номера страниц, многоколоночная вёрстка и таблицы
  распознаются плохо.
- Изображения не переносятся.
- Для сканов без текстового слоя (нет OCR) результат будет пустым.

## CLI

```sh
pyfb2 convert book.pdf book.fb2     # автоопределение направления
pyfb2-pdf2fb2 book.pdf              # узкая команда
```
