Готово. Создан класс `Fb2ToTxtConverter` для преобразования FB2 в обычный текст.

## Что сделано

Новый модуль `pyFB2/pyFB2/fb2_to_txt.py`, переиспользующий `Fb2Parser` и структуры `fb2_structures.py`. **Внешних зависимостей нет** — только стандартная библиотека (`textwrap`).

### Публичный API (в стиле остальных конвертеров)
```python
from pyFB2.fb2_to_txt import Fb2ToTxtConverter

converter = Fb2ToTxtConverter(include_toc=True, line_width=80)
text = converter.convert("book.fb2")             # → str
path = converter.write("book.fb2", "book.txt")   # → Path (запись файла, utf-8)
converter.write("book.fb2")                      # → book.txt рядом с исходником
```

### Что поддерживается
- **Метаданные**: название книги (с подчёркиванием `=`), автор(ы), аннотация.
- **Заголовки**: `<title>` → уровень 1/2 подчёркивается `=`/`-`, глубже — отступом (`heading_offset`, `max_heading_level`, `heading_underline`).
- **Абзацы** `<p>`: отступ первой строки (`paragraph_indent`, по умолчанию 4 пробела) + пустая строка между абзацами.
- **Разметка** (`strong`/`emphasis`/`code`/`a`/…): в plain text **снимается**, остаётся только текст; inline `<image>` → `[изображение]` (`image_placeholder`).
- **Блоки**: `<subtitle>`, `<empty-line>`, `<cite>` и `<epigraph>` (двойной отступ, автор через `—`), стихи `<poem>/<stanza>/<v>` (строки с отступом), `<table>` (колонки, выровненные пробелами).
- **Оглавление** (опционально, `include_toc=True`): список заголовков с отступами по уровню.
- **Перенос строк** (`line_width=N`) через `textwrap` — для читаемости на узких экранах/в `.txt`-читалках.

### Опции
| Параметр | По умолчанию | Назначение |
|---|---|---|
| `heading_offset` | `1` | уровень заголовков верхнего уровня |
| `max_heading_level` | `6` | ограничение глубины |
| `include_metadata` | `True` | заголовок/автор/аннотация |
| `include_annotation` | `True` | аннотация книги |
| `include_epigraphs` | `True` | эпиграфы |
| `include_toc` / `toc_title` | `False` / `"Оглавление"` | оглавление |
| `paragraph_indent` | `"    "` | отступ абзаца |
| `blank_line_between_paragraphs` | `True` | пустая строка между абзацами |
| `heading_underline` | `True` | подчёркивание `=`/`-` |
| `image_placeholder` | `"[изображение]"` | заглушка (или `None`) |
| `line_width` | `None` | ширина переноса (None — без переноса) |
