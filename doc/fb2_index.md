# Индекс библиотеки и поиск (`fb2_index`)

Модуль `pyFB2/fb2_index.py` — SQLite-база с метаданными книг и (опционально)
их текстом. Используется для каталога, дедупликации и поиска.

```text
library/  --build-->  fb2_index.db  --search/find-->  результаты
```

## Схема базы

| Таблица | Содержимое |
|---|---|
| `books` | по строке на файл: путь, размер, mtime, SHA-1, кодировка, статус, ошибка |
| `authors` | авторы книги (last/first/middle/nickname + полное имя) |
| `titles` | название, серия, номер серии, язык, год, `id` из `<document-info>` |
| `genres` | жанровые коды с `match` |
| `author_facts` | внешние сведения об авторе (страна, годы жизни) + кэш |
| `book_text` | **FTS5**: `path`, `title`, `body` (UNINDEXED) и `folded` (поисковый) |

`book_text` создаётся при открытии базы (`CREATE VIRTUAL TABLE IF NOT
EXISTS`). Если SQLite собран без FTS5, индекс работает без текстового
поиска — в лог уходит предупреждение, `search_text` возбуждает
`Fb2OperationError`.

Обновление инкрементальное: файлы с неизменившимися `size`/`mtime`
пропускаются; если у книги ещё нет текста в FTS (например, база собрана с
`--no-text`), она переиндексируется автоматически.

## Поиск по метаданным

```python
from pyFB2 import Fb2Index

with Fb2Index("library.db") as idx:
    idx.build("C:/Books", recursive=True)          # индекс + текст книг
    idx.search_books("Толстой", by="author")
    idx.search_books("Детство", by="title", limit=10)
```

Поля: `author`, `title`, `series`, `genre`, `year`, `any` (по умолчанию —
все сразу). Сравнение идёт через SQL-функцию `fb2_norm` (регистр и `ё`/`е`
не важны), поэтому «ПЁТРОВ», «петров» и «пётров» находят «Петров».

Возвращается список `BookHit(path, title, authors, series, year)`.

## Полнотекстовый поиск

```python
    hits = idx.search_text("ёжик", limit=20)
    for hit in hits:                                # TextHit
        print(hit.title, hit.rank, hit.snippet)
```

* синтаксис FTS5: `AND`/`OR`/`NOT`/`NEAR`, `"точная фраза"`, `слово*`;
* простые слова автоматически ищутся как префиксы (`ежик` → `ежик*`), что
  компенсирует отсутствие стеммера для русского языка: «ежик» найдёт
  «ежика», «ежиков» (отключить — `prefix=False`);
* `ё` и `е` не различаются в обе стороны (нормализуется и текст, и запрос);
* результаты упорядочены по релевантности (`bm25`), `snippet` содержит
  фрагмент с подсветкой `[совпадение]`;
* некорректный запрос (`(` , незакрытая кавычка, `NOT` без операнда)
  возбуждает `Fb2OperationError`.

Нюансы реализации:

| Решение | Причина |
|---|---|
| два столбца (`body` — оригинал, `folded` — ё→е + нижний регистр) | сниппет показывает исходный текст, а ищет по нормализованному |
| свой `make_snippet` вместо `snippet()` | подсветка в оригинальном регистре (в т.ч. «[Ёжик]») |
| `title` включается в начало `body` | название тоже находится полнотекстовым поиском |
| `text_limit` (по умолчанию 200 000 символов) | защита индекса от книг-гигантов |

## CLI

```bash
pyfb2 index build library/                 # индекс (+ текст книг)
pyfb2 index build library/ --no-text       # только метаданные
pyfb2 index build library/ --text-limit 50000
pyfb2 index search "Толстой"               # метаданные: все поля
pyfb2 index search "Детство" --by title
pyfb2 index find "красная шапка"           # полнотекстовый поиск
pyfb2 index find "волк NEAR лиса" -n 5 --snippet-length 300
pyfb2 index stats                          # в т.ч. «с текстом в индексе: N»
```

Модульный CLI повторяет те же команды:

```bash
python -m pyFB2.fb2_index build library/ -r --hash
python -m pyFB2.fb2_index find "ёжик" -n 10
```

## Ограничения

- Морфология русского не поддерживается (в FTS5 нет русского стеммера) —
  используйте префиксный поиск или короткие основы (`толст*`).
- Индекс хранит текст, поэтому база растёт примерно на размер текста книг;
  `--no-text` и `--text-limit` ограничивают рост.
- Полнотекстовый поиск ищет по тому, что попало в `book_text` (заголовки,
  абзацы, стихи, цитаты, таблицы); сноски и метаданные — вне текста.
